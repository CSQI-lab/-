# 记单词 App

一个纯网页的「主屏幕 App」——iPhone Safari 添加到主屏幕后，像普通 App 一样点开就用，**完全离线、不用电脑、不用网络**。

---

## 一、在电脑上看（调试用）

```bash
python -m http.server 8000 --directory app
```

浏览器打开 http://localhost:8000 。这只是本地预览，**正式使用时不需要开电脑**。

---

## 二、在 iPhone 上装（只需做一次）

iOS 的规则：App 必须先通过一个 **HTTPS 网址**装一次（就像从 App Store 下载一次）。装完后文件和数据都在手机本地，之后开飞行模式也能用。

### 第一步：拿到一个 HTTPS 网址（二选一）

**方式 A：从 WorkBuddy 复制完整分享链接**

在 WorkBuddy 里打开这个应用的预览 → 找到「应用详情 / 分享」→ **复制完整分享链接** → 发到 iPhone（微信文件传输助手即可）。

> 注意：直接复制浏览器地址栏里的短链接会显示「链接不完整」，必须用应用详情页里那个带访问参数的完整链接。

**方式 B：拖到免费静态托管（推荐，网址永久稳定）**

1. 把项目根目录的 `vocab-app-upload.zip` 发到任何一台电脑并解压，得到 `app/` 文件夹
2. 打开 <https://app.netlify.com/drop>
3. 把 **`app/` 文件夹**（不是 zip）拖进页面虚线框
4. 几秒后得到一个 `https://xxxx.netlify.app` 网址，复制它

> 国内也可换成 Gitee Pages、腾讯云 EdgeOne Pages 等静态托管，步骤类似。

### 第二步：添加到主屏幕（iPhone 上做）

1. 用 **Safari** 打开上面那个 HTTPS 网址
2. 点底部「分享」按钮（方框带向上箭头）
3. 向下滚动，选「**添加到主屏幕**」
4. 确认名称「记单词」→ 点「添加」

桌面出现蓝色「记单词」图标。**从这一刻起，电脑和网络都不再需要了**：页面文件在 Service Worker 缓存里，词库和学习记录在手机 IndexedDB 里，朗读用 iPhone 自带语音引擎，每天 10 个词也是手机本地按日期生成的。

> iOS 16.4 及以上才有图标角标；更低版本不影响使用，只是角标变成 App 内红点。

## 四、功能一览

| 功能 | 说明 |
|---|---|
| 五个页签 | **今日 / 已学 / 词典 / 复习 / 我的**（每个页签只显示两个字，没有单字图标） |
| 今日页「确定」 | 右上角蓝色「确定」按钮。加词删词弄完后点它，今天的单词就锁定（数量随意，少于 10 个或多于 10 个都行）；锁定后加号框和垃圾桶一起隐藏，按钮变成「已确定」。**这也是「算不算学过」的分界线**：没点确定之前，这批词只是草稿，不进「已学」、不参与同义词自动归组、也不进「全部已学复习」 |
| 加号加词 | 词卡列表底部有一个**虚线框（与词卡等大）**，里面是蓝色圆圈包着的加号。点开弹出搜索面板，英文或中文都能搜，点「＋ 添加」加进今日学习（面板不关，可连加几个） |
| **搜索规则** | **按字母顺序前缀匹配**：输入 `lar` 只出 large / largely / larva 这类以 lar 开头的词，`alarm` 不会出现。输入中文（如「放弃」）则匹配释义里包含这些字的词。词典页、加词面板、同义词编辑器共用这一套（`db.js` 的 `searchWords`） |
| **输入框滑动全选** | 手指在**任何输入框**里横向滑一下（>8px 且横向为主），框里的文字整体被选中，直接打字就是替换、按删除就是清空。**这个手势期间页面不会跟着滚**（`preventDefault` + `touch-action: pan-y`），只有输入框响应；纵向滑动照常滚动页面。用全局事件委托实现（`ui.js` 的 `setupSlideSelect`），新加的输入框自动生效 |
| 词数提示 | 单词卡上方显示「已有 N 个词」 |
| **难度切换** | 三档：易（接近四级，词频 1000–3039）/ 中（六级，3039–6495，默认）/ 难（高于六级，6495+）。按钮在**顶部标题栏「今日」右边**（蓝底白字，只显示当前档位一个字），点一下**向右横向**弹出三个选项（带依次滑入动画），切换后当天 10 词立刻重抽。调难度：`app/js/config.js` 的 `VOCAB_LEVELS`（`minFrq` 越大越难） |
| 词卡 | 单词右侧是蓝底胶囊音标，同一行最右是**收藏五角星**（黄色实心＝已收藏）；单词下方是喇叭图标（朗读时音波脉冲动画）；垃圾桶图标在**卡片外面右侧**；不显示考试标签 |
| **收藏（三类，三级页面）** | 单词卡、俗语卡、同义词组卡右上角都有五角星，点一下收藏 / 取消。**收藏后整张卡片变淡黄底，星标自己的颜色不变**（未收藏灰、已收藏黄）。「我的 → 收藏」进的是**收藏菜单**，分「单词 / 同义词 / 俗语」三行（各带数量），点某一行再进该类列表，列表左上角「‹ 返回」回菜单。收藏存本地数据库，随备份一起导出 |
| 我的页 | 三块：**个人资料**（头像 + 用户名，点一下弹出编辑；头像可选 6 个预设 emoji，或从相册传图 → **出现圆形取景框，自己拖动 / 缩放选择要显示的那一块**，再点「用这张」）、**收藏**（一行，带数量）、**备份**（导出 / 导入，备份里含收藏）。原本的「数据」卡片已按要求去掉 |
| 已学页 | 「单词」按日期倒序列出（最近 30 天）。**只显示点过「确定」的日期**；没确定时显示空态并提示今天有几个词待确定。**日期是一个按钮**，点一下才展开当天单词，再点收起（箭头会转 90°）；日期右侧有**垃圾桶**，可删掉这一天的整份单词组（删的是今天 → 自动回到「今日」页变回草稿，可以重新编辑、重新确定）；展开后每张词卡右侧也有垃圾桶，可清掉单个词的记录。另有「俗语」「同义词」两个子标签。过去日期的记录默认算已学（那天已过去、无法补点确定，也兼容早期版本没有 confirmed 字段的数据），判定统一在 `db.js` 的 `isLearnedDaily()` |
| **俗语** | 在「已学 → 俗语」里点「＋ 新建俗语」，弹出底部抽屉填原文 / 含义 / 例句后保存（和同义词组的操作方式一样）；列表里每条也有「编辑」按钮可改。三行用不同样式区分：**原文**深色加粗、**含义**蓝底胶囊、**例句**浅灰底 + 左侧竖线 + 斜体。每张卡右侧外面有**垃圾桶图标**，点了删掉这条 |
| 词典页 | 搜索整个词库（8122 词），纯查询，不影响学习记录 |
| 同义词整理 | **不分区展示**：顶部一个「＋ 新建同义词组」按钮，下面所有组用同一种卡片列出 —— 有组名的是自己建的（带「编辑」按钮 + 右侧垃圾桶），只有词的是从学过的词自动归出来的（只读）。**手动整理进组的词，不会再出现在自动归组里**。编辑器是底部抽屉：**加词后搜索框自动清空**方便接着搜；**没点保存就关闭只存草稿、不会生成新词条**，下次打开编辑器自动把草稿填回输入框；只有点遮罩空白或「关闭」才退出 |
| 朗读 | 点喇叭图标读出单词（iPhone 系统语音，不联网） |
| **动效** | 页面切换淡入 + 上移 8px；**「我的」里收藏菜单 ↔ 三类列表切换**、**词典搜索结果**也有淡入（`view-enter`）；底部抽屉从下方滑入、关闭时下滑淡出；按钮 / 图标 / 日期行按下有轻微回弹；底部页签选中时上浮 2px。系统开了「减弱动态效果」会自动全部关掉 |
| 搜索手感 | 词典页输入有 **160ms 防抖**（停手才查，连续打字不会一直闪），结果整块淡入一次 |
| 每天 10 词 | 每天首次打开自动生成，图标角标显示待学数 |
| **复习（三个入口）** | ① **今日单词复习**：**只算点过「确定」的那批词**，没确定时显示「今天学了 0 个词」且不给按钮；② **全部已学复习**：从所有学过的词里按权重抽，最多 `REVIEW_QUIZ_COUNT`（默认 10）题；③ **俗语复习**：从所有俗语里随机抽，最多 10 条。三张卡都是**有内容才显示「开始复习」按钮**，没内容就不显示 |
| **出题方向完全随机** | 每题独立随机决定「看英文写中文」还是「看中文写英文（中译英）」，不追求两种题型次数相等，可能连着出好几道同一种。**每重新开一轮，所有题全部重新随机**。一轮内题目固定，切页签回来不会变 |
| **自己判对错** | 提交答案后**不自动判分**，而是同时亮出「正确英文 + 中文释义」，由你对照自己写的，点「✓ 写对了」或「✗ 写错了」。中文说法多、拼写差一两个字母不该算错，自己判最准 |
| **可反复测试** | 考完成绩单底部有「再测一轮（题目重新随机）」，回复习页也能再点开始，次数不限 |
| **抽题权重** | 仅「全部已学复习」用：艾宾浩斯到期情况（超期越久越容易被抽到，未到期权重很低但不为零）+ 历史正确率（越低越容易被抽到）+ 今天答错情况（今天错过的词权重再放大）。参数在 `app/js/config.js` 的 `REVIEW_WEIGHTS` |
| **成绩单** | 考完显示总分和正确率，下面分「答错 N 个」「答对 N 个」两张卡片逐条列出：单词 + 音标 + 正确释义；答错的还会显示「你写的」。底部可「再测一轮」或「返回复习页」 |
| 艾宾浩斯复习 | 间隔 1/2/4/7/15/30 天，答对推进、答错回退，双向默写考核 |

## 五、词库说明

已内置**真实词库**（ECDICT，MIT 开源，词典数据约 340 万条中筛出）：

| 项目 | 数量 |
|---|---|
| 单词 | 8000 个（其中牛津 3000 核心词 3461 个） |
| 短语 | 122 个 |
| 近义词组 | 1331 组（每组带中文辨析说明） |
| 文件体积 | 3.47 MB（首次打开下载一次，之后离线可用） |

覆盖考试标签：中考 / 高考 / 四级 / 六级 / 考研 / 雅思 / 托福 / GRE。每天抽哪些词由「难度」决定（见第四节），默认「中」：词频 3039–6495，即 calculate / tendency / uniform / scholarship 这个难度（六级）。

**词库升级机制（自动）**：`db.js` 每次启动对比 `words.json` 的版本号（生成日期 + 词数），变了就自动重灌词库。用户自己加的俗语、手动建的同义词组、全部学习进度都会保留。给已安装的手机换新词库只需三步：替换 `data/words.json` → `sw.js` 的 CACHE 版本号 +1 → 用户下次打开自动完成。

**重新生成词库**（改筛选范围、词数上限）：

```bash
# 1. 获取 ECDICT 原始数据。
#    推荐：npm 包 ecdict@0.0.4 自带完整数据（ecdict.csv 65MB + resemble.txt 近义词辨析），
#    国内从 npm 镜像下载很快；GitHub 直连经常不通。
# 2. 运行预处理（标签、词数上限都在参数里）：
python tools/ecdict_prep.py --input <ecdict.csv> --resemble <resemble.txt> --output app/data/words.json --max 8000
# 3. 把 app/sw.js 里的 CACHE 版本号 +1
```

> **改完代码记得把 `app/sw.js` 里的 `CACHE` 版本号 +1**，否则已安装到主屏幕的手机会继续用旧缓存。
>
> **离线缓存策略（v17 起）**：`js / css / html` 采用「联网优先 + 1.5 秒超时回退缓存」——
> 联网时总是拿服务器上的最新一套代码并写回缓存，断网/慢网才用缓存，所以不会出现
> 「新页面配旧模块」的白屏。图标、词库等大文件仍是「缓存优先」省流量。
> 安装时核心代码必须**整套**缓存成功，装不完整就本次作废、继续用旧版（宁可功能旧，也不白屏）。
> 万一真的遇到模块报错，页面会自动清一次缓存并刷新（一个会话只修一次，不会死循环）。
> 如果看到红框报错，按一次刷新即可恢复。

## 八、数据备份

- **导出**：我的页 →「导出备份」→ 存到 iPhone「文件」App 或微信收藏
- **导入**：我的页 →「导入备份」→ 选文件恢复

> iPhone 偶尔会清理长期不用的网页数据，定期导出备份是唯一可靠的保全方式。
